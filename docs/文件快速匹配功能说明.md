# 批量快速匹配业务说明

## 1. 目标与范围

本文定义“批量快速匹配”能力：对一组外部标题进行快速判定，识别其在本地文件库中的匹配程度。

该能力用于“已下载识别”与“候选提示”，不等同于精确去重。

---

## 2. 输入与输出语义

### 输入

- `queries`：待匹配标题列表
- `limit`：每个 query 返回的候选上限
- `presence_filter`：候选范围过滤条件

### 输出

按 query 返回匹配结果：

- `match_level`：匹配等级
- `confidence`：置信度（0~1）
- `reason`：判定依据摘要
- `hits`：候选命中列表

---

## 3. 匹配等级定义

- `downloaded`：高度确定为已下载
- `likely`：较高概率为同作品
- `same_author`：作者高度相关，但标题不够接近
- `different`：不应视为同一作品

---

## 4. 业务流程

1. **解析查询标题**
   - 提取作品名、作者/社团等结构化信息。

2. **召回候选**
   - 作者线索召回。
   - 标题关键词召回。
   - 合并去重并截断到合理候选规模。

3. **候选评分**
   - 作者匹配得分。
   - 标题匹配得分（含噪音词剔除与卷号识别）。

4. **等级判定**
   - 根据作者分与标题分映射到匹配等级。

---

## 5. 评分规则

### 5.1 作者分

- 作者强一致：高分
- 仅社团/组织一致：中分
- 无作者相关性：低分

### 5.2 标题分

- 先移除噪音标记（如版本附注、发行附注等）。
- 识别卷号/话数等序列信息。
- 规则优先级：
  1. 去噪后完全一致 → 高分
  2. 去噪一致但卷号冲突 → 明确降分
  3. 其余情况按编辑距离/相似度计算

---

## 6. 关键判定原则

1. “同作者但不同卷”不得误判为 `downloaded`。
2. 标题噪音差异（如 DL 版标记）不应导致同一本被判不同。
3. 批量场景应保证稳定响应，候选上限可控。

---

## 7. 验收口径

1. 同一本作品（仅噪音词差异）应判为高等级匹配。
2. 明确不同卷应降级到 `same_author` 或 `different`。
3. 接口可稳定处理批量输入并返回结构化结果。
4. `presence_filter` 可正确影响候选范围。
