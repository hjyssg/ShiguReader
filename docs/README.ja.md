## 紹介

ShiguReader は、ローカル / LAN 環境でコンテンツを整理・閲覧するためのツールです。目標は「導入が簡単で、すぐ使え、個人コレクション管理に向いている」ことです。

### できること

- **スキャンと整理**: ローカルのコンテンツディレクトリを高速にインデックス化。
- **統一された閲覧体験**: 複数形式のコンテンツを Web UI で一貫して閲覧。
- **情報管理**: アイテム情報や閲覧履歴を記録・管理。
- **ローカル重視**: 家庭内ネットワーク / 小規模チームでの利用に最適化。

### こんな人におすすめ

- 分散したファイルをまとめて管理したい個人ユーザー。
- プライバシー重視で、クラウドにアップロードしたくないユーザー。
- EXE を配布してそのまま使ってもらいたいシナリオ。

### 実行方法

- **開発モード**: ソースコードから直接起動。
- **簡単実行**: 単体 EXE にパッケージしてダブルクリック起動。
- **配布対応**: 配布用 ZIP の生成をサポート。
