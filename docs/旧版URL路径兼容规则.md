# URL 携带文件路径规则（简版）

## 目标

解决“filepath 放进 URL 后解析错误”的问题，保证前后端拿到的是同一个路径。

## 统一规则

1. filepath 放到 query 参数前，必须先做 URL 编码（`encodeURIComponent` 语义）。
2. 解析 query 时，`+` 按空格处理（兼容旧行为）。
3. 如果路径里本来就有 `+` 字符，必须编码成 `%2B`。
4. URL 只能有一个 `?`，避免出现 `??`。

## 典型问题

- 路径含空格或 `+` 时，最容易被解析错。
- 解析错后就会变成“前端看着对，后端找不到文件（404）”。

## 验收

1. 含空格路径可正常打开。
2. 含 `+` 路径（用 `%2B` 编码）可正常打开。
3. 同一链接在不同端解析结果一致。
