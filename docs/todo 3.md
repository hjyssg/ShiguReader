### 🚀 Claude 审计指令：React TS + Node.js 全栈优化

**审计原则：所有优化必须以“系统稳定性”为前提，禁止引入破坏性变更。**

#### **1. IO 与后端性能 (Node.js/TS)**

* **[ ] 串行变并行：** 检查无依赖的 `await` 接口调用，改用 `Promise.all()`。
* **[ ] 数据库索引：** 检查 `WHERE/JOIN` 字段是否有索引，防止全表扫描。
* **[ ] 分页强制化：** 检查所有列表接口是否强制 `limit/offset`，禁止一次性拉取大数据。
* **[ ] 流式处理：** 涉及文件或大数据导出时，必须使用 `Stream` 而非 `Buffer`。


#### **3. 代码质量与单元测试 (UT)**

* **[ ] 核心逻辑覆盖：** **后端 UT Coverage 必须 ≥ 70%**。重点测试：鉴权逻辑、复杂计算、数据转换。
* **[ ] 边界测试：** 针对 API 的 `null`、`undefined`、`Empty Array` 情况编写测试用例。
* **[ ] 异步 Mock：** 确保所有的外部服务调用（DB/第三方 API）在测试中均被正确 Mock。

#### **4. 对接与类型安全**

* **[ ] 解构安全：** 检查前端对 API 返回值的解构，必须使用可选链 `?.` 或默认值。
* **[ ] 类型闭环：** 搜索 `any`，将其替换为精准的 TS `Interface`。
* **[ ] 异常透传：** 确保后端 4xx/5xx 错误能被前端捕获并展示为用户友好的 Toast 提示。
