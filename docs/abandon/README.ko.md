## 소개

ShiguReader는 로컬 / LAN 환경에서 콘텐츠를 정리하고 열람하기 위한 도구입니다. 목표는 "바로 사용할 수 있고, 배포가 쉽고, 개인 컬렉션 관리에 적합"한 경험을 제공하는 것입니다.

### 주요 기능

- **스캔 및 정리**: 로컬 콘텐츠 디렉터리를 빠르게 인덱싱합니다.
- **통합 열람**: 다양한 콘텐츠 형식을 일관된 웹 UI에서 열람합니다.
- **정보 관리**: 항목 정보와 열람 이력 등을 기록·관리합니다.
- **로컬 중심 설계**: 가정 네트워크 / 소규모 팀 환경에서 클라우드 의존 없이 사용하기 좋습니다.

### 추천 대상

- 흩어진 파일을 한곳에서 관리하고 싶은 개인 사용자
- 프라이버시를 중시하여 클라우드 업로드를 원하지 않는 사용자
- EXE로 패키징하여 바로 배포/실행하고 싶은 시나리오

### 실행 방식

- **개발 모드**: 소스 코드에서 직접 실행
- **간편 실행**: 단일 EXE 파일로 패키징 후 실행
- **배포 지원**: 배포용 ZIP 생성 지원
