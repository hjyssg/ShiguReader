# Technical Notes

## 中文

本项目技术上遵循“尽量使用标准技术库、减少自定义基础设施”的原则。

- 后端：FastAPI + SQLModel + SQLite
- 前端：React + Vite
- 打包与启动：`build_tools` 下脚本

环境安装与本地设置建议直接使用 **vibe coding** 工作流完成（按提示自动安装依赖、初始化环境并完成基础配置）。

如需具体命令，请参考：

- [backend/README.md](backend/README.md)
- [frontend/README.md](frontend/README.md)
- [build_tools/BUILD.md](build_tools/BUILD.md)

## English

This project follows a “use standard libraries/frameworks, avoid unnecessary custom infrastructure” approach.

- Backend: FastAPI + SQLModel + SQLite
- Frontend: React + Vite
- Build/launch scripts: under `build_tools`

For environment installation and local setup, we recommend using a **vibe coding** workflow to complete dependency installation and initial configuration with guided prompts.
